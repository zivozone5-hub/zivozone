# ZIVOZONE V1170 — FORENSIC VISUAL CORE

## مبدأ التنفيذ
تعديل النواة الحالية مباشرة مع الحفاظ على خصائص المختبر السابقة، وليس إضافة runtime أو طبقة جديدة.

## محفوظ بالكامل
- الدخول السينمائي
- WebGL
- الصوت وقراءة النص
- 25 قضية
- 10 أسئلة لكل قضية
- 10 حقائق لكل قضية
- المشتبهون والقرار النهائي
- ZIVO AI
- XP/ZIVO event
- إعادة التحقيق وملفات القضايا والعودة للموقع

## تطوير V1170
- بطاقات القضايا أصبحت مرئية وسينمائية بدل نص فقط.
- مشهد التحقيق أصبح يحتوي على نقاط أدلة قابلة للنقر.
- فحص الدليل يعرض حقيقة مرتبطة بالقضية داخل المشهد.
- القرار النهائي يعرض ملخص المحقق قبل اختيار المشتبه.
- تحسين الهاتف بدون مكتبات مدفوعة.

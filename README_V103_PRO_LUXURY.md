# ZIVOZONE V103 PRO LUXURY

هذه النسخة مبنية فوق V102 بدون إزالة Firebase أو محرك التحديات.

## ما تم تنفيذه
- واجهة Mobile-First مستوحاة من التصميم المرجعي: بطاقات فاخرة، تدرجات داكنة، أزرار واضحة، شبكة تحديات محسنة للموبايل.
- شريط المحفظة والتعدين في أعلى الموقع بشكل أصغر وأكثر فخامة.
- التعدين اليومي يبقى 24 ساعة، والمكافأة +0.50 ZIVO تضاف للمحفظة عند نجاح العملية وفق قواعد Firestore الحالية.
- حساب المدير الوحيد: `raefalbtish@gmail.com`، ولا يتم إنشاء Player Profile له ولا يدخل في التعدين.
- زر ADMIN يفتح غرفة الإدارة مباشرة داخل واجهة احترافية، مع المستخدمين، آخر ظهور، المستوى، XP، ZIVO، الألعاب، النشاط، وحالة Firebase/Hosting/Domain.
- شاشة الشروط والموافقة قبل إنشاء الحساب، مع توضيح أن ZIVO رصيد افتراضي داخل ZIVOZONE وليس نقودًا أو استثمارًا.
- إعادة التحدي تستخدم ملفًا تكيفيًا محليًا: كلما كرر اللاعب التحدي، يتم ترجيح الأسئلة الأعلى صعوبة، ومع الأداء الكامل ترتفع أولوية المستوى الصعب أكثر.
- لا توجد Cloud Functions مطلوبة لتشغيل واجهة V103؛ النشر الحالي متوافق مع Spark في المسارات الموجودة.

## النشر
```cmd
firebase use
firebase deploy --only hosting,firestore:rules
```

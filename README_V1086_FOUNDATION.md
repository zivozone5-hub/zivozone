# ZIVOZONE V1086 — Foundation Build

This is the new baseline built from V1085 Player Center.

## Kept
- Challenges and challenge engine
- Dark Room / psychological full-screen experience and generated ambient audio
- “من أنا؟” identity experience
- Player profile and cloud result history
- ZIVO wallet
- 24-hour mining
- ZIVO Hub
- Firebase Auth / Firestore
- Free hosting architecture (no payment processor added)

## Consolidated
- One desktop player utility rail
- One mobile bottom dock: Profile / Wallet / Mining / Hub
- Login button becomes the player's name after login and opens the profile
- Mobile hamburger exposes the secondary site navigation
- Duplicate legacy launchers are removed/hidden
- Logout uses a confirmation message before signing out

## Important
ZIVO remains a virtual in-platform currency. Real-money purchasing is intentionally not enabled in this free foundation build.

# ZIVOZONE V1154 — TRUE FREE ARABIC MATCH CENTER

## لماذا V1154؟
V1153 كانت تعرض واجهة صحيحة، لكن ملف `data/matches/index.json` كان فارغًا. V1154 تعالج مسار البيانات نفسه.

### الهندسة
- GitHub Actions هو طبقة المزامنة الوحيدة.
- المتصفح لا يتصل بمزود المباريات.
- جلب يوم واحد لكل بطولة، لأن طلبات النطاق الزمني العامة ليست موثوقة بنفس الدرجة.
- مزودان عامان ESPN مع إعادة المحاولة.
- نافذة 15 يومًا: 7 سابقة + اليوم + 7 قادمة.
- ملفات يومية `YYYY-MM-DD.json` + `index.json` + `manifest.json`.
- يمنع استبدال بيانات سليمة ببيانات فارغة إذا فشل المصدر.
- الـWorkflow يعمل عند أي push إلى `main`، بالإضافة إلى كل 15 دقيقة وmanual dispatch.

## التشغيل
بعد رفع محتويات المشروع إلى جذر المستودع:
1. افتح Actions.
2. سيظهر `تحديث ZIVOZONE - مركز المباريات`.
3. شغّله يدويًا مرة واحدة إن أردت التحقق فورًا.
4. يجب أن تنشأ ملفات `data/matches/*.json`.

إذا فشل مزود ESPN بالكامل، لن يتم نشر بيانات فارغة فوق آخر بيانات سليمة.

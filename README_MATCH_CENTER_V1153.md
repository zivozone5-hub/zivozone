# ZIVOZONE V1153 — مركز المباريات العربي

هذه النسخة تعيد بناء مركز المباريات كـCore مستقل، مع فصل مصدر البيانات عن الواجهة.

## البنية

`ESPN public scoreboard → GitHub Actions → data/matches/index.json → Match Center UI`

المتصفح لا يتصل بمصدر المباريات مباشرة، لذلك لا تعتمد الواجهة على CORS أو على نجاح طلبات ESPN من هاتف المستخدم.

## التشغيل المجاني

1. ارفع محتويات النسخة إلى جذر مستودع GitHub في فرع `main`.
2. يجب أن يظهر الملف:
   `.github/workflows/matches-update.yml`
3. بعد الـPush سيعمل Workflow تلقائيًا، ويمكن تشغيله يدويًا من **Actions → تحديث ZIVOZONE - مركز المباريات**.
4. عند نجاحه ستتحدث:
   `data/matches/index.json`
   و`data/matches/manifest.json`.
5. GitHub Pages سيعيد بناء الموقع عند الـPush الذي يحتوي بيانات جديدة.

## قواعد الدوريات

القائمة تحتوي على دوريات مرشحة من نقاط ESPN العامة. أي دوري يفشل في الاستجابة أثناء المزامنة يُسجل ضمن `failedLeagues` ولا يظهر في واجهة الموقع. لا توجد قائمة وهمية للدوري الأردني أو العراقي أو القطري أو الإماراتي أو المصري عندما لا يكون لها مصدر مجاني موثوق في هذا المصدر.

## الواجهة

- عربية بالكامل.
- Mobile First.
- بطاقة مباراة كبيرة على الهاتف.
- شبكة ثلاثية على الشاشات الواسعة، وثنائية على الأجهزة المتوسطة، وعمود واحد على الهاتف.
- أمس / اليوم / غدًا / القادمة / السابقة / المفضلة.
- مباشر / قادمة / نتائج.
- بحث وبطولات ومفضلة.
- تفاصيل المباراة الأساسية من البيانات المزامنة.

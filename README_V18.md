# ZIVOZONE V18 — Challenge Bank & Anti-Repeat

Built on V17 without replacing the existing challenge banks or Firebase configuration.

Added:
- Expanded Logic Lab, Pattern Break and Focus Trap banks.
- 10 questions per run with difficulty 1→10.
- Non-MCQ answer formats (numeric/text/sequence/logic).
- Anti-repeat memory for up to 500 question IDs.
- Fresh-run engine with fallback when a bank is exhausted.
- Challenge catalog API for future center UI integration.

Existing V17 timer, pressure, player system, Firebase, audio, languages, news and ads are preserved.

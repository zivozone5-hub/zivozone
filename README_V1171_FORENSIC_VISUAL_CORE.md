# ZIVOZONE V1171 — FORENSIC VISUAL CORE

هذه النسخة استبدال هندسي مباشر للنواة الجنائية السابقة، وليست طبقة فوقها.

## ما تم الحفاظ عليه
- 25 قضية
- 10 أسئلة لكل قضية
- 10 حقائق لكل قضية
- 3 مشتبهين في كل قضية حيثما كانت بيانات القضية كذلك
- قرار نهائي وربط بالـXP/ZIVO
- ZIVO AI للتلميحات دون كشف الحل
- WebGL للمشهد
- صوت سينمائي وقراءة عربية
- العودة للموقع وملفات القضايا وإعادة التحقيق

## ما تم تغييره
- حذف صفحة اللاعب القديمة المضمنة في `index.html`؛ `PlayerHub` أصبح المالك الوحيد لرحلة اللاعب.
- المختبر الآن يعمل بمسار من 5 فصول: المشهد → الأدلة → المشتبهون → خط الزمن → القرار.
- كل سؤال يغيّر الفصل والمشهد البصري والنص الإرشادي.
- تحسين السرد العربي وحجم النصوص.
- استبدال بوستر المختبر القديم ببوستر SVG سينمائي جديد داخل الأصل نفسه.
- لا يوجد runtime جنائي ثانٍ أو طبقة Legacy جديدة.

## الاستضافة
كل شيء يعمل كملفات ثابتة، بدون Cloud Functions أو خدمة 3D مدفوعة.

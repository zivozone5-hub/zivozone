# ZIVOZONE V1166 — FORENSIC CASE CORE

## الهدف
استبدال نظام المختبر الجنائي السابق بتجربة تحقيق خيالية غير دموية، تبدأ بالدخول السينمائي ثم تنتقل إلى 10 ملفات قضايا مستقلة.

## دورة التجربة
1. الدخول السينمائي.
2. شاشة ملفات القضايا — 10 قضايا.
3. فتح القضية ومشاهدة مسرحها وملخصها والمشتبه بهم.
4. فحص 4 أدلة متتابعة مع أسئلة استدلالية.
5. شاشة القرار الأخير واختيار المشتبه به.
6. إغلاق القضية وعرض النتيجة والتفسير.
7. إرسال نتيجة القضية إلى Player Core عبر `Player.addProgress` وإطلاق `zivozone-result`.

## البنية
- `core/modules/forensic-case-core.js` — مالك النظام الوحيد للقضايا.
- `core/styles/forensic-case.css` — نظام العرض الخاص بالمختبر.
- `core/modules/challenges.js` — يمرر تشغيل `forensic` إلى Forensic Case Core بدل الـrunner القديم.
- تم حذف بنك الأسئلة الجنائي القديم من `question-bank.js` ومنطق الحزمة القديمة.

## ملاحظة
القضايا والشخصيات خيالية وغير دموية. لا توجد إجابات أو أدلة مولدة من الواقع، ولا يتم تقديم الاستنتاجات كإرشاد تحقيق حقيقي.

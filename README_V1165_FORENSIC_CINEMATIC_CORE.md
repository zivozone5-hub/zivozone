# ZIVOZONE V1165 — FORENSIC CINEMATIC CORE

## الهدف
استبدال تجربة دخول المختبر الجنائي القديمة بتجربة سينمائية عربية مستقلة، خفيفة، Mobile-First، وبدون طبقات Legacy.

## ما تم استبداله
- حذف أصول `assets/forensic/` القديمة.
- حذف مراجع المشاهد القديمة من بنك الأسئلة واستبدالها بأصول `assets/forensic-cinema/`.
- إزالة محرك الـDark Room البصري القديم من مسار المختبر الجنائي.
- بناء دخول سينمائي جديد داخل Challenge Core نفسه.

## تجربة الدخول
1. المستخدم يضغط المختبر الجنائي من أي مكان على البطاقة.
2. شاشة كاملة مظلمة بأسلوب مختبر تحقيقي.
3. مراحل عربية قصيرة:
   - تهيئة مسرح القضية
   - فتح سجل الأدلة
   - تحليل التسلسل الزمني
   - القضية جاهزة
4. انتقال سينمائي إلى الأسئلة بدون زر Start إضافي.
5. عند إغلاق التجربة تتم إزالة حالة السينما من DOM.

## مبادئ هندسية
- لا Firebase Functions.
- لا API خارجي.
- لا اعتماد على صور أو خدمات خارجية.
- CSS/JS داخل الـCore.
- كل نص الدخول بالعربية.
- `prefers-reduced-motion` مدعوم.
- الأصول الجديدة مملوكة للمشروع وموجودة محليًا.

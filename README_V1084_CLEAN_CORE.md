# ZIVOZONE V1084 — Unified Core Clean

## Goal
A clean production direction: one main runtime, one main stylesheet, a minimal home page, and no additive V103–V1081 UI layers.

## Preserved
- Firebase Authentication / Firestore integration
- Challenge engine and challenge data
- Multilingual system
- Sports/news and fixtures modules
- ZIVO economy functions and server-checked mining/perfect-score rewards
- Owner/admin monitoring
- ZIVO AI integration hook

## Home principle
Home focuses on Hero, Challenges, Sports, and Player. AI and Identity are opened from Player Hub instead of occupying the main page.

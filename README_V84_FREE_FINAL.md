# ZIVOZONE V84 — FREE FINAL

V84 consolidates the player/challenge/economy/news behavior while preserving the existing ZIVOZONE interface.

## Reward policy
- ZIVO challenge reward is granted only for a perfect score: all questions correct and no timeout.
- Base perfect-score reward: 10 ZIVO.
- Active-time bonus: +1 ZIVO per 10 active minutes, capped at 10 bonus tiers, and released only alongside a perfect challenge.
- Guests do not receive cloud ZIVO rewards.

## Unified ZIVO UI
- One gold ZIVO launcher is used for the wallet/store.
- Legacy floating ZIVO launchers are removed/hidden.

## News
- Upper rail: sports only.
- Lower rail: general news only; sports headlines are filtered out.
- Faster ticker motion than the previous release.
- GitHub Actions remains the hourly refresh mechanism; Firebase Functions/Blaze are not required for news.

## Free/Spark scope
The current economy is an internal platform balance. Without a trusted server backend, it must not be treated as a cash-equivalent or tradable token.

# ZIVOZONE V1167 — FORENSIC CINEMATIC CASE CORE

Full replacement of the V1166 forensic case runtime.

- 25 fictional non-graphic cases
- Difficulty: متوسط / متقدم / صعب / خبير
- 3D-style SVG cinematic scenes per case with scan and depth animation
- Arabic-first large typography
- WebAudio procedural cinematic SFX; no paid assets or external audio dependency
- Case -> Scene -> Evidence -> Logic -> Suspect -> Verdict -> Player Progress
- Dynamic filtering and progress state
- No legacy forensic asset dependency
- Mobile-first and desktop responsive

The visual scenes are 2.5D/isometric SVG compositions with cinematic motion; this keeps the project free and lightweight on Firebase Hosting while giving a 3D-like presentation.

# ZIVOZONE V1161 — REAL LIVE FOOTBALL MATCH CORE

هذه النسخة تستبدل Match Center القديم بالكامل. لا توجد طبقة Fixture قديمة.

## مصدر البيانات
المتصفح يقرأ Scoreboard الحقيقي من ESPN لكل بطولة محددة وتاريخ محدد، ثم يطبع حالة المباراة والنتيجة والشعارات. عند فتح تفاصيل مباراة، يتم طلب Summary الحقيقي لإظهار الأحداث المتاحة.

## السلوك
- أمس / اليوم / غدًا
- البطولات الكبرى أولًا
- قادمة / مباشر / انتهت
- تحديث المباريات المباشرة كل 30 ثانية
- تفاصيل المباراة من Summary عند توفرها
- لا بيانات وهمية
- ذاكرة JSON محلية اختيارية كـfallback فقط
- لا Firebase Functions
- لا API مدفوع

## البطولات الأساسية
دوري أبطال أوروبا، الإنجليزي، الإسباني، الإيطالي، الألماني، الفرنسي، الهولندي، البرتغالي، التركي، البرازيلي، الأرجنتيني، الأمريكي، المكسيكي، السعودي، دوري أبطال آسيا للنخبة، دوري أبطال أفريقيا.

إذا لم تُرجع البطولة مباريات في ذلك اليوم، لا يتم اختلاق مباريات لها.

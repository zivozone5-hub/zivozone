# ZIVOZONE V1086 — Unified Pro

This release keeps the V1085 Clean Core and restores the existing V1081 capabilities through the existing consolidated runtime:

- Admin Command Center: owner-only Firebase/Firestore monitor.
- Player Profile: existing V1081 player profile + wallet + store view.
- ZIVO Hub: existing V37 player hub and its existing challenge/mission/competition entry points.
- Expanded Challenge Bank: retained in the consolidated runtime; the PRO-1 manifest is included for traceability.
- Mobile-first UI: account, player and hub entry points are placed in the existing profile section instead of adding floating launchers.
- No new backend, Cloud Functions, paid APIs, or paid services.
- No new runtime layer: these are unified entry points into engines already present in the consolidated application.

The original V1085 release should be retained as rollback.

# ZIVOZONE V1169 — FORENSIC CINEMATIC CASE CORE

إعادة بناء كاملة لنظام المختبر الجنائي، مع الحفاظ على فكرة الدخول السينمائي وإصلاح دورة الخروج والقرار النهائي.

## ما تم بناؤه
- دخول سينمائي Full Screen مع مشهد WebGL ثلاثي الأبعاد حقيقي.
- زر تشغيل الصوت مع توافق المتصفحات التي تمنع الصوت التلقائي.
- مؤثرات صوتية مولدة داخل المتصفح + Ambient خفيف.
- سرد عربي واضح للقضية + خيار قراءة الملخص والسؤال صوتيًا.
- 25 قضية، لكل قضية 10 أسئلة و10 حقائق و3 مشتبهين.
- أسئلة أكبر وأكثر وضوحًا.
- مسرح تحقيق WebGL حقيقي داخل المتصفح بدون مكتبات خارجية مدفوعة.
- مساعد ZIVO AI اختياري للتلميحات دون كشف الحل.
- إصلاح زر الخروج: يعود إلى `#challenges` ويعيد المستخدم إلى الموقع.
- زر «العودة إلى الموقع» موجود أيضًا بعد إغلاق القضية.
- إعادة بناء الـruntime بدل إضافة طبقات فوق النظام السابق.

## الخطة المجانية
لا توجد Cloud Functions أو خدمة مدفوعة مطلوبة لهذه الوحدة. WebGL وWebAudio يعملان محليًا داخل المتصفح، وAI يبقى اختياريًا عبر التكامل الموجود في المشروع.

# ZIVOZONE V1152 — مركز المباريات العربي المجاني

## ما تم إصلاحه
- Workflow المباريات يعمل تلقائيًا عند دفع النسخة إلى `main`، وليس فقط يدويًا أو كل 15 دقيقة.
- إزالة `cache: npm` من GitHub Actions لأن المشروع لا يحتوي `package-lock.json`.
- أول Push إلى `main` يطلق مزامنة المباريات تلقائيًا.
- بعد نجاح المزامنة تُحفظ ملفات JSON داخل `data/matches`، فيقرأها GitHub Pages من نفس النطاق.
- تحديث كل 15 دقيقة بعد ذلك.
- استخدام `Asia/Amman` في الحسابات الزمنية.
- طلب نطاق زمني واحد لكل دوري أولًا، مع رجوع تلقائي إلى طلبات يومية عند فشل النطاق.
- لا اتصال مباشر من متصفح الزائر بمصدر ESPN.
- لا API مدفوع ولا Firebase Functions.
- أي دوري لا يستجيب من المصدر المجاني لا يظهر كمصدر متاح.

## طريقة التشغيل
1. ارفع محتويات هذه النسخة إلى فرع `main` في مستودع ZIVOZONE.
2. لا تحتاج إلى تشغيل Workflow يدويًا في أول مرة؛ حدث `push` سيشغله تلقائيًا.
3. افتح GitHub → Actions → `تحديث مركز المباريات`.
4. يجب أن ترى تشغيلًا جديدًا باسم `تحديث مركز المباريات`.
5. عند نجاحه، ستظهر ملفات `data/matches/YYYY-MM-DD.json` و`index.json`.
6. بعدها يقرأ الموقع البيانات من نفس الاستضافة.

## ملاحظة
مصدر ESPN العام ليس API تجاريًا مضمونًا بعقد SLA. لذلك Match Core مصمم بحيث يمكن تبديل Provider لاحقًا دون إعادة بناء واجهة المركز.

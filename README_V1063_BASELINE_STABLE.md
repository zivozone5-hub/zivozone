3. إضافة أيقونات PWA 192/512 وإعدادات manifest كاملة.
4. إضافة تسجيل Service Worker من `index.html`.

6. الحفاظ على محركات التحديات والاقتصاد الحالية دون إعادة كتابة منطقها في هذه المرحلة.

# ZIVOZONE V1151 — مركز المباريات العربي

## لماذا ظهرت شاشة «تعذر تحديث البيانات»؟
النسخة السابقة كانت تعتمد على ملفات `data/matches/*.json` التي ينشئها GitHub Actions.
إذا لم يتم تشغيل الـWorkflow مرة واحدة، فلن تكون هذه الملفات موجودة في الاستضافة.

## الحل في V1151
- مزامنة مجانية عبر GitHub Actions.
- إنشاء `data/matches/index.json` كمصدر موحد للمركز.
- إنشاء ملفات يومية لأمس/اليوم/غدًا والقادم والسابق.
- إعادة المحاولة الآمنة من داخل المركز.
- لا API مدفوع ولا Firebase Functions.
- واجهة عربية Mobile-First.

## التشغيل بعد رفع المشروع إلى GitHub
1. ارفع الملفات إلى المستودع.
2. افتح GitHub → Actions.
3. اختر **تحديث مركز المباريات**.
4. اضغط **Run workflow** مرة واحدة.
5. انتظر انتهاء المهمة بنجاح.
6. بعدها ستظهر ملفات `data/matches/index.json` وملفات التواريخ.
7. انشر الموقع من جديد إذا كان GitHub Pages لا يلتقط التغييرات تلقائيًا.

بعد أول تشغيل، الـWorkflow يعمل تلقائيًا كل 15 دقيقة.

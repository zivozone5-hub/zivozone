# ZIVOZONE V1157 — مركز المباريات العربي النهائي

## ما تم إصلاحه
- اكتشاف مباريات **كل البطولات التي يعيدها TheSportsDB في اليوم** بدل حصر الموقع في قائمة ثابتة.
- إثراء اليوم / أمس / غدًا من ESPN للمسابقات المدعومة، عبر GitHub Actions وليس من المتصفح.
- دمج المصدرين وإزالة التكرارات مع الاحتفاظ بالشعارات والملعب والنتيجة.
- حفظ 7 أيام سابقة + 7 أيام قادمة + اليوم.
- عدم حذف آخر بيانات ناجحة عند تعطل مصدر مؤقت.
- المتصفح لا يستدعي ESPN؛ هذا يمنع CORS والـrate-limit من كسر مركز المباريات.
- واجهة عربية وMobile-First.
- أسماء البطولات الشائعة تُعرض بالعربية، والبطولات المكتشفة غير المعروفة تظهر كـ«بطولة كرة القدم» بدل عرض اسم إنجليزي خام.
- لا Firebase Functions ولا API مدفوع.

## GitHub Actions
الملف:
`.github/workflows/matches-update.yml`

ويعمل:
- عند Push إلى `main`
- كل 15 دقيقة
- يدويًا من Actions

## رفع النسخة
**ارفع محتويات ZIP إلى جذر المستودع، وليس ZIP نفسه داخل مجلد.**

يجب أن يظهر:
```
zivozone/
├── .github/workflows/matches-update.yml
├── data/matches/
├── scripts/fetch_matches.py
├── core/modules/match-center.js
└── index.html
```

بعد أول Commit:
`GitHub → Actions → ZIVOZONE - تحديث مركز المباريات - جميع البطولات`

إذا لم يظهر هذا الـWorkflow، فهذا يعني أن `.github/workflows/matches-update.yml` لم يصل إلى جذر المستودع.

## حدود التغطية
لا يوجد مصدر مجاني واحد يضمن كل بطولة في العالم حرفيًا. التصميم هنا يجعل TheSportsDB مصدر الاكتشاف اليومي لكل البطولات التي يعيدها، وESPN مصدر إثراء للمسابقات التي يدعمها. بذلك لا نعرض بطولات وهمية ولا نحذف بطولات حقيقية لمجرد أنها ليست في قائمة ثابتة.

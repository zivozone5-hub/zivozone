# ZIVOZONE Question Bank AI Factory

Generate questions offline, then validate before import.

Validation gates:
1. Exactly one correct answer.
2. Four distinct options for choice questions.
3. Clear, unambiguous wording.
4. Difficulty 1-10 matches cognitive demand.
5. Unique question ID.
6. No duplicate semantic question in same challenge.
7. Correct answer is independently verified.
8. No sensitive/personal-data prompts.
9. Language fallback to Arabic/English.
10. Human/admin approval before production publication.

The production client does not call a paid AI API per player.
